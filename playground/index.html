Components and authoring tips

Change the named controls near the top of a template. auto inherits prepared defaults; () and false are explicit overrides.

#ik.overdue-diseases(notice, columns: 2, include-dose: true)
#ik.immunization-history(notice,
  diseases: ("Measles", "Mumps", "Rubella"),
  ignore-agents: (), include-other: true, show-validity: auto)

Branding and envelope coordinates are editable in the source. Label overrides live in config/translations/. Package documentation is available in Files & assets.

Examples use fixed prepared facts. Preprocessing and reference configuration changes take effect when you run the native CLI; use explicit Typst arguments to test presentation here.

A .typ download uses this project's package and assets. A complete project includes those dependencies. Exporting creates a draft, not approval of revised notice wording.
