# ImmuKnow Studio

[ImmuKnow Studio](https://immuknow.phiz.ca/) is a separate browser editor and preview environment. [ImmuKnow Template](https://github.com/WDGPH/ImmuKnow-Template) supplies starter notices, Settings, translations and example branding. Core supplies the standalone pipeline, schemas and shared Typst components.

Studio and Template integrations pinned to an earlier Core interface must adapt to the standalone `prepare`, `resources`, and `run` commands. Check the versions and instructions of those projects before relying on their setup helpers. The native executable uses fonts installed on the workstation. See [getting started](getting_started.md) and [template authoring](phu_templates.md).
