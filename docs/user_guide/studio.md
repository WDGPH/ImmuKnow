# ImmuKnow Studio

[ImmuKnow Studio](https://immuknow.phiz.ca/) is a separate browser editor and preview environment. [ImmuKnow Template](https://github.com/WDGPH/ImmuKnow-Template) supplies starter notices, Settings, translations and example branding. Core creates the PDF notices and supplies the shared Typst components.

Check the versions and instructions of Studio and Template before using them with Core. The standalone executable uses fonts installed on the workstation. See [getting started](getting_started.md) and [template authoring](../developer_guide/templates.md).
